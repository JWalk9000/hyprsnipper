# HyprSnipper v1.0.4

Date: 2026-01-08

Patch release to fix AppImage runtime issues.

## Bug Fixes

- **AppImage: Fixed host binary access**: AppRun now preserves host PATH, allowing access to `hyprctl`, `grim`, `slurp`, and `wl-clipboard`
- **AppImage workflow**: Corrected GitHub Actions workflow to use versioned AppImage filenames

## Technical Details

The AppImage runtime now:
1. Preserves `APPIMAGE_ORIGINAL_PATH` to access host binaries
2. Ensures common binary locations (`/usr/local/bin`, `/usr/bin`, `/bin`) are in PATH
3. Allows Wayland/Hyprland tools to be called from within the containerized environment

## Notes

This is a maintenance release focused on AppImage packaging. The core functionality from v1.0.3 remains unchanged.
