# HyprSnipper v1.0.3

Date: 2026-01-08

This release fixes critical window selector geometry issues and improves multi-monitor support.

## Highlights

- **Fixed window selector geometry**: Selector window now correctly sizes itself based on monitor aspect ratio
- **Multi-monitor compatibility**: Proper handling of offset monitor positions in Hyprland compositor
- **Aspect-ratio preservation**: Preview window maintains accurate monitor proportions (16:9, 16:10, etc.)
- **Self-controlled sizing**: Uses `setFixedSize()` to prevent compositor window rules from overriding dimensions

## Bug Fixes

- Window selector no longer shows incorrect size or position across different workspace layouts
- Fixed scaling calculations to use actual screen geometry instead of window bounding boxes
- Corrected coordinate transformation for windows on offset monitors
- Selector now centers within available work area, avoiding panels and bars

## Configuration

- Updated Hyprland window rule syntax in README to v2 format:
  ```conf
  windowrule = match:title HyprSnipperSelector, float on
  ```

## Technical Details

The window selector now:
1. Derives preview size from active monitor's aspect ratio (base 800px width)
2. Uses `screen.geometry()` for accurate monitor coordinate space
3. Scales preview to fit within `availableGeometry()` with 64px margin
4. Applies `setFixedSize()` to prevent compositor resize events

## Known Issues

- None reported for this release
